STUDY DESK: install on your phone

1. Upload every file in this folder to the ROOT of a GitHub repo (index.html, manifest.json, sw.js and the 4 PNG icons).
2. Repo Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
3. Open https://YOUR-USERNAME.github.io/REPO-NAME/ on your phone.
   Android Chrome: menu > Install app.
   iPhone Safari: Share > Add to Home Screen.
4. Progress (learned words, saved words, reviewed formulas) is stored on that device. After install it also works offline.
5. To update later: replace the files in the repo and bump the cache name in sw.js (for example studydesk-v2 to studydesk-v3).
